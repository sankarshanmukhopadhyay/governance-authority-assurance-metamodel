# Review Evidence

Store review evidence in the domain-specific directories below this path. Each published file must be referenced by a review register, finding, disposition, or attestation.

Do not place secrets, personal data without a lawful and documented basis, temporary files, editor files, caches, or unapproved working notes in this directory. Empty `.gitkeep` files preserve directory structure but are excluded from package manifests and checksums.
