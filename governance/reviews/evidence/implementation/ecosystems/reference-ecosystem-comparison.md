# Reference Ecosystem Comparison

The Governed Ecosystem Operations pattern was pressure-tested against structural characteristics found in mature qualified-intermediary ecosystems, with the vLEI Ecosystem Governance Framework used as a principal reference point.

The comparison considered primary and subordinate governance instruments, qualified issuers, recurring qualification, contractual participation, credential-specific governance, service obligations, assurance, third-party providers, status publication, suspension, termination and transition.

## Transferable findings

GAAM already supplies the core semantics needed to distinguish identity, authority, delegation, evidence, assurance, runtime decisions, effects, accountability and remedy. The principal implementation friction lies in composing these semantics into an institutional operating model that admits, qualifies, supervises and replaces intermediaries.

The reusable additions are therefore patterns and guidance for qualification lifecycle, framework composition, organisational authority chains, multi-object assurance, supplier flow-down and continuity. Technology-specific identifier, credential, cryptographic or trust-root choices remain outside the generic pattern.

## Reference limitations

This evidence does not claim endorsement by GLEIF, does not reproduce the vLEI framework, and does not assert vLEI conformance with GAAM. It uses publicly documented ecosystem structures solely as an implementation stress test.
