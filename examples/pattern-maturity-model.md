# Implementation Pattern Maturity Model

| Level | Meaning | Minimum evidence |
|---|---|---|
| Conceptual | Roles and governance flow | Narrative and diagram |
| Structural | Machine-readable artifacts | Manifest and schema fixtures |
| Behavioural | Positive and negative outcomes | Behavioural-vector references |
| Operational | Lifecycle and enforcement | Runtime and state handling |
| Assurance-ready | Requirement and evidence mapping | Traceability and limitations |
| Interoperability-tested | Independent implementations | Cross-validator evidence |

A pattern must not claim a maturity level unless all lower-level evidence is present.
