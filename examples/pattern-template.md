# Implementation Pattern Template
Use this structure for new patterns:

1. Purpose and applicability
2. Governance problem
3. Actors and accountable roles
4. Selected profiles
5. Architecture and trust boundaries
6. Authority and delegation model
7. Control-document baseline
8. Runtime decision flow
9. Evidence and assurance model
10. Lifecycle and revocation behaviour
11. Notice, review, and remedy
12. Privacy considerations
13. Security considerations
14. Affected-party considerations
15. Failure modes
16. Requirement traceability
17. Included artifacts
18. Validation procedure
19. Conformance limitations
20. Extension points
