# Draft Profile Candidates

These profile candidates organise future requirements for evaluation without extending the GAAM v0.9.0 conformance surface. They are not profiles that an implementation may claim, and their identifiers MUST NOT appear in a GAAM v0.9.0 conformance claim.

| Candidate | Primary pressure addressed |
|---|---|
| [Governed Ecosystem Operations](governed-ecosystem-operations/) | Participant qualification, framework composition and intermediary lifecycle |
| [Organisational Authority](organisational-authority/) | Appointment, mandate, approval and representation chains |
| [Institutional Continuity](institutional-continuity/) | Succession, exit, degraded operation and status continuity |
| [Privacy and Inference Governance](privacy-and-inference-governance/) | Collection, inference, observability and privacy boundaries |
| [Cross-Jurisdiction Governance](cross-jurisdiction-governance/) | Governing-law conflicts, recognition and mandatory constraints |
| [Market and Infrastructure Governance](market-and-infrastructure-governance/) | Gatekeeper power, concentration, capture and switching constraints |
| [Advanced Agent Orchestration](advanced-agent-orchestration/) | Agent state, plan steps, multi-agent authority and composite effects |

Promotion requires implementation evidence, independent review, explicit change control and a later versioned normative release.
