# Jurisdiction, Market, and Systemic Governance

{% include gaam-meta.html %}

> This is an informative candidate concept for evaluation. It does not modify GAAM v0.9.0 requirements, schemas, profiles, vocabularies, or conformance semantics.

Cross-border governance must distinguish governing law, regulatory authority, territorial reach, subject jurisdiction, service jurisdiction, data jurisdiction, recognition basis, mandatory law, public-policy exceptions, and emergency intervention.

Market governance should address gatekeeper power, discriminatory recognition, unilateral delisting, switching costs, assurance shopping, registry capture, interoperability withholding, dependency on a single trust root, and concentration among agent or infrastructure providers.

## Evaluation questions

- Can the current GAAM model represent the concept without ambiguous interpretation?
- Do multiple implementation patterns require the same semantics?
- Is a draft profile, experimental schema, vocabulary, or behavioural vector necessary?
- What privacy, security, affected-party, market, and continuity consequences arise?
- What evidence would justify normative promotion?
