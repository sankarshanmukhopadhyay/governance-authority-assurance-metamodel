# Affected Parties and Remedy Execution

{% include gaam-meta.html %}

> This is an informative candidate concept for evaluation. It does not modify GAAM v0.9.0 requirements, schemas, profiles, vocabularies, or conformance semantics.

Affected parties may include direct subjects, represented principals, bystanders, dependants, communities, workers, competitors, downstream relying parties, and public-interest representatives. A future model should support individual and collective standing, delegated representation, evidence access, interim protection, correction, cross-border redress, and remedy propagation.

Remedy execution should identify the affected effect, remedy authority, responsible executor, deadline, downstream systems, completion evidence, residual harm, and escalation route.

## Evaluation questions

- Can the current GAAM model represent the concept without ambiguous interpretation?
- Do multiple implementation patterns require the same semantics?
- Is a draft profile, experimental schema, vocabulary, or behavioural vector necessary?
- What privacy, security, affected-party, market, and continuity consequences arise?
- What evidence would justify normative promotion?
