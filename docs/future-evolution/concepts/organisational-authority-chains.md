# Organisational Authority Chains

{% include gaam-meta.html %}

> This is an informative candidate concept for evaluation. It does not modify GAAM v0.9.0 requirements, schemas, profiles, vocabularies, or conformance semantics.

Organisational authority may flow through identity, appointment, office holding, mandate, role authority, transaction approval, instruction, technical control, and execution. These relationships are not all delegations. Candidate relations include `appoints`, `authorises`, `approves`, `ratifies`, `instructs`, `controls`, `represents`, `acts-for`, `succeeds`, and `withdraws-mandate-from`.

The model must preserve accountable attribution across each link.
