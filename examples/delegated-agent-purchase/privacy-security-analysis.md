# Privacy and Security Analysis
Privacy controls minimise decision receipts, restrict evidence audiences, limit correlation, and apply retention periods tied to review and legal needs. Security controls protect authority sources, policy versions, state freshness, evidence integrity, enforcement points and package publication. Redaction must not destroy the evidence required for meaningful challenge.
