# Lifecycle and Revocation
The pattern distinguishes issuance, activation, restriction, suspension, revocation, expiry, supersession and remediation. Runtime components must obtain sufficiently current state. When revocation state is unavailable, the declared failure policy governs; high-risk effects fail closed.
